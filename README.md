## About me

I am a Computer Engineering student at the **University of Alicante** who enjoys building software beyond coursework and using projects as a way to understand how systems really work.

I like working across layers: from application logic and APIs to interfaces, tooling and system integration. Rather than treating technologies as isolated skills, I prefer combining them into projects that solve a concrete problem or let me explore an idea in depth.

That approach has led me to work on local AI tools, interactive C++ visualizations, web applications, distributed systems, multiplayer game systems and a heavily customized Linux environment.
